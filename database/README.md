# Database design

This folder stores the relational schema and seed data for the PingPongBros venue system.

## Files

- `schema.sql` — PostgreSQL objects and core enforcement rules.
- `seed.sql` — seed tables and sample bookings, members, and payments.
- `migrations/` — place migration scripts here when deploying to a fresh database.
- `erd/` — keep ERD and diagram exports here.
- `docs/` — additional project design notes.
